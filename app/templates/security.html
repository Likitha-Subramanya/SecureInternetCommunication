🛡️ Security Verification

Cryptographic techniques used by SecureChat

🔒

AES-256-GCM

The original message is encrypted using AES-256-GCM before it is stored or transmitted.

✓ ACTIVE
🔑

RSA-2048

RSA-2048 is used to protect the AES session key so that the encryption key itself is not stored as plain data.

✓ ACTIVE
🛡️

HMAC-SHA256

HMAC-SHA256 is used to verify that the encrypted message has not been modified during storage or communication.

✓ ACTIVE
🔐

Password Hashing

User passwords are hashed before being stored in the database instead of being stored as plain text.

✓ ACTIVE

Important: The plaintext message is not stored in the messages table. The database stores the encrypted ciphertext, nonce, RSA-protected AES key, and HMAC value. The receiver gets the original message only after the stored data is successfully processed and verified.
